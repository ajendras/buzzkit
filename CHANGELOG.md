## [0.1.0] - 2026-11-27

### Added

- Fluent DSL — Build layered rhythms and textures with @HapticBuilder and operators for sequencing, looping and amplitude envelopes.
- Audio → Haptics — Convert short WAV tones or generated sine waves into accurate haptic event streams playable on the trackpad.
- Live Preview — SwiftUI pattern editor with real-time sliders and instant playback for rapid iteration.
- Effect Library — Ready-to-use presets including heartbeats, sci-fi pulses, musical notes and notification families.
- CLI Trigger — Invoke any pattern or conversion directly from Terminal scripts with the bundled haptikit executable.
- Verified Fidelity — Unit tests guarantee pattern serialization, audio conversion accuracy and device capability handling.
- Safe Wrapper — Modern async CoreHaptics wrapper with automatic error recovery and respect for system haptic settings.
- Accessibility First — Dynamic intensity scaling and optional reduced-motion compliance built into every API.
